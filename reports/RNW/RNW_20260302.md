## 6. 성장성 분석

### TAM 및 시장 기회

| 지표 | 규모 |
|------|------|
| TAM | ~$300B (인도 RE 2030 투자 추정) |
| SAM | ~$80B (유틸리티 규모 RE IPP 시장) |
| 현재 점유율 | ~5-7% (인도 RE 설비 중) |
| 시장 CAGR | 15.0% (2025-2030) |

### 주요 성장 동력

1. **인도 정부 500GW 목표**: 2024년 200GW → 2030년 500GW, 연 50GW+ 신규 설치 필요
2. **C&I 직접 PPA 시장 급성장**: 연 18.8% CAGR, Google 150MW PPA 등 실적
3. **설비용량 확대**: 현재 19.2GW 포트폴리오 (운영 + 건설 + 수주)
4. **RTC 하이브리드 프로젝트**: 풍력+태양광+BESS 결합, 높은 타리프 수령 가능
5. **수직 통합 (Manufacturing)**: PLI 정책 활용 태양광 모듈 국산화

### 텐배거 가능성: 보통 (중장기 조건부)

| 기준 | 충족 여부 |
|------|----------|
| 매출 성장 20%+ | 부분 충족 (TTM 50%+, 연간 19%) |
| 이익률 개선 | 충족 (적자 → 흑자 전환) |
| 낮은 시장 침투율 | 충족 (5-7% 점유율) |
| 소형/중형주 | 충족 ($2B 시가총액) |
| 낮은 기관 보유 | 부분 충족 (제한적 커버리지) |
| 낮은 부채 | **미충족** (D/E 6.32배) |

유틸리티 인프라 특성상 기술 성장주 수준의 주가 상승은 어렵지만, 부채 상환 + FCF 흑자 전환 시 밸류에이션 리레이팅 가능성 있음.

**성장성 등급: ★★★☆ (3.5 / 5)**

- **긍정적 요소**: RNW 주가가 $5대로 시장에서 외면 받는 중 → 린치가 선호하는 "무관심 종목" 특성
