## 3. 피터 린치 분류

### 분류: **대형우량주(Stalwart) → 고성장주(Fast Grower) 전환 하이브리드**

**근거**:

| 기준 | 평가 |
|------|------|
| 매출 성장률 | FY2025 +18.3% (고성장주 기준 20-25%에 근접) |
| 영업이익률 추세 | -22%(2021) → +10.7%(2025), 급격한 레버리지 실현 |
| 시가총액 | $145B 대형주 (전통적 텐배거 후보와는 거리) |
| 수익성 전환 | 2023년 첫 GAAP 흑자, 전형적 턴어라운드 완성 후 성장 가속 |
| PER 수준 | 15.4x (대형우량주 범위 12-15x 상단) |

린치의 프레임워크에서 Uber는 순수한 단일 카테고리보다는 **턴어라운드를 완성한 후 대형우량주에서 고성장주로 전환 중인 하이브리드**에 가장 가깝다. 매출 성장률 18%는 대형우량주(10-12%)를 상회하지만 고성장주(20-25%)에는 약간 미달하는 경계 구간이다. 영업이익 성장률(+100% YoY)과 FCF 성장률(+41%)은 고성장주의 특성에 부합한다.

## 10. 위험 요인

### 피터 린치 Red Flags 점검

| 위험 신호 | 해당 여부 | 상세 |
|----------|----------|------|
| Diworsification | **해당** | Uber Freight($5.1B)가 소비자 플랫폼과 이질적. 수익성 미달. |
| 과도한 부채 | 부분 해당 | 순부채 $26.1B이나, FCF $9.8B 대비 2.7배로 관리 가능 |
| 단일 고객 의존 | 비해당 | 수억 명 분산 소비자, 10% 초과 고객 없음 |
| 재고 급증 | 비해당 | 플랫폼 기업, 물적 재고 없음 |
| 내부자 대량 매도 | 부분 해당 | 정기적 10b5-1 플랜 매도, 공개 시장 매수는 부재 |
| 핫한 산업의 핫한 기업 | 부분 해당 | AV 테마 연계이나, PER 15x는 과열과 거리 |

### 기타 주요 리스크

1. **자율주행 구조적 위협** (핵심): Waymo/Tesla가 독자 B2C 플랫폼으로 전환 시 Uber의 중간자 역할 약화
2. **드라이버 분류 규제**: EU/영국 정직원 분류 확대 시 비용 구조 악화
3. **순이익 변동성**: 투자자산 평가이익에 따른 분기별 순이익 급변 (Q3 $6.6B vs Q4 $0.3B)
4. **SBC 과다**: 연간 $1.8B 주식보상비용 (FCF의 18.3%)
