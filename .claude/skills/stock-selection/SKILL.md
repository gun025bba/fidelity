# 종목 선정 (Stock Selection)

시가총액·섹터 등 조건에 맞는 미국 상장(NYSE/NASDAQ) 후보 티커를 스크리닝하고, 이미 최근에 분석한 티커는 제외한 뒤, 사용자가 선택한 티커를 바로 `/analyze`로 이어서 분석하는 대화형 스킬입니다.

## Step 1: 스크리닝 조건 해석

사용자 요청에서 아래 조건을 해석하세요. 명시되지 않은 값은 기본값을 사용합니다.

- **섹터**: 특별한 언급이 없으면 CLAUDE.md의 "선호 섹터"(기술/헬스케어/소비재)를 기본값으로 사용합니다 → `Technology,Healthcare,Consumer Cyclical,Consumer Defensive`. "유틸리티", "원자재" 등 CLAUDE.md의 회피 섹터는 기본값에 포함하지 않습니다.
- **시가총액 범위**: 사용자가 피터 린치의 6가지 분류 중 특정 카테고리를 언급하면 그에 맞게 조정하세요 (예: "고성장주/텐배거 후보" → 소형~중형 대역인 기본값 $3억~$100억을 그대로 사용, "대형우량주(Stalwarts)" → 예: $100억~$2000억 등으로 상향, "저평가된 대형주" → 시총 하한을 높이는 식). 사용자가 숫자를 직접 주면 그 값을 그대로 사용합니다.
- **제외 기간**: 기본값 3개월. 사용자가 다른 개월 수를 말하면 그 값을 사용합니다.
- **결과 개수**: 기본값 20개. 사용자가 더 많이/적게 요청하면 조정하세요.

## Step 2: 의존성 확인

```bash
python3 -c "import yfinance" 2>/dev/null || pip install -r requirements.txt
```

설치에 실패하면 사용자에게 실패 사유를 그대로 전달하고 중단하세요 (임의로 다른 데이터 소스로 대체하지 않습니다).

## Step 3: 스크리닝 실행

Step 1에서 정리한 조건으로 스크리너를 실행하세요:

```bash
python3 tools/screen_candidates.py \
  --sectors "Technology,Healthcare,Consumer Cyclical,Consumer Defensive" \
  --market-cap-min 300000000 \
  --market-cap-max 10000000000 \
  --exclude-recent-months 3 \
  --limit 20
```

이 스크립트는 `data/analysis_index.txt`(최근 분석 기록)와 `data/watchlist.txt`(이미 대기 중인 티커)를 자동으로 확인하여 이미 제외한 결과만 출력합니다. 스크립트는 어떤 파일도 수정하지 않습니다(읽기 전용). 스크리너 조회가 실패하면(네트워크 오류, yfinance 미설치 등) 에러 메시지를 그대로 사용자에게 전달하세요.

## Step 4: 후보 제시

출력된 후보 목록(티커/시가총액/섹터/종목명)을 사용자에게 보여주세요. 결과가 없으면 조건을 완화할지 사용자에게 물어보세요.

## Step 5: 선택한 티커를 바로 분석으로 체이닝

사용자가 지금 바로 분석할 티커를 고르면, 고른 티커들에 대해 **하나씩 순서대로** `analyze` 스킬을 호출하세요 (Skill 도구, `skill: "analyze"`, `args: "{TICKER}"`). 여러 개를 골랐다면 병렬이 아니라 순차적으로 실행합니다 (analyze 스킬 내부에서 이미 6개 서브 에이전트를 병렬 실행하므로, 티커 단위까지 병렬화하면 리소스 경합이 발생합니다).

## Step 6: 나머지 후보 처리

지금 분석하지 않기로 한 후보 티커가 있다면, `data/watchlist.txt`에 추가할지 사용자에게 확인하세요. 사용자가 동의하면 기존 파일 포맷(한 줄에 하나, `#` 주석 가능)과 중복 방지 규칙을 지키며 파일 끝에 append 합니다 (이후 `dispatch.sh` 야간 크론이 순서대로 처리). 사용자가 원하지 않으면 아무것도 쓰지 않고 종료합니다.
