### Step 1: 기본 정보 확인
먼저 웹 검색으로 {TICKER}의 기본 정보를 빠르게 확인하세요:

- 이 정보를 모든 서브 에이전트에게 전달합니다.

### Step 2: 6개 서브 에이전트 병렬 실행
다음 6개 서브 에이전트를 **동시에 병렬로** 실행하세요:

1. **financial-analyst**: "{TICKER}의 재무제표를 분석해주세요. 최근 3-5년 데이터를 기반으로 피터 린치의 재무 건전성 체크리스트를 적용하세요."

2. **business-analyst**: "{TICKER}의 사업 모델을 분석해주세요. 린치의 30초 테스트, 경쟁 우위(Moat), 경영진 평가를 포함하세요."

3. **growth-analyst**: "{TICKER}의 성장 잠재력을 분석해주세요. TAM/SAM/SOM, 성장 동력, 텐배거 가능성을 평가하세요."

4. **industry-analyst**: "{TICKER}가 속한 산업과 경쟁 환경을 분석해주세요. 포터의 5 Forces와 주요 경쟁사 비교를 포함하세요."

5. **sentiment-analyst**: "{TICKER}의 최근 3개월 뉴스와 시장 센티먼트를 분석해주세요. 애널리스트 의견, 내부자 거래, 린치의 칵테일 파티 지표를 적용하세요."

6. **valuation-analyst**: "{TICKER}의 밸류에이션을 분석해주세요. PEG 비율을 중심으로 상대/절대 가치를 평가하고 적정 주가 범위를 산출하세요."

### Step 3: 결과 종합 및 보고서 생성
모든 서브 에이전트의 결과를 수신한 후:

1. **피터 린치 6가지 분류 결정**: 분석 결과를 종합하여 해당 종목이 어떤 카테고리에 속하는지 결정
2. **종합 투자 의견 도출**: Strong Buy / Buy / Hold / Sell / Strong Sell
3. **종합 점수 산출**: 6개 영역의 등급을 종합한 최종 점수
4. **나의 투자 철학 적합성**: CLAUDE.md의 "나의 투자 철학"과의 부합 여부

### Step 4: 보고서 파일 생성
